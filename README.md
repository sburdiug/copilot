# Copilot

[![CI](https://github.com/Magerko/copilot/actions/workflows/ci.yml/badge.svg)](https://github.com/Magerko/copilot/actions/workflows/ci.yml)

Слушает разговор, распознаёт речь локально, замечает вопросы и показывает короткий
ответ в небольшом оверлее — с опорой на загруженные документы. Windows.

## Возможности
- Локальное распознавание речи (whisper.cpp): аудио не уходит в сеть и не пишется на диск.
- Модель ответов на выбор: локальная (Ollama, LM Studio) или облачная по ключу
  (OpenAI, Anthropic, Gemini, AnyModel, любой OpenAI-совместимый). Ключи — в DPAPI.
- Ответы опираются только на загруженные документы; не найденное помечается `[нет в резюме]`.
- Снимок выделенной области экрана → vision-модель или локальный OCR.
- Оверлей не забирает фокус, автоподстройка высоты, регулируемая прозрачность.
- Окна можно исключить из захвата экрана (флаг Windows SetWindowDisplayAffinity;
  поддерживается не всеми программами захвата).
- Сворачивание в трей, аварийная остановка, продолжение прошлой сессии.
- Учёт расхода по платным моделям и лимиты в настройках. Офлайн-режим блокирует внешние вызовы.
- Без аккаунта и своего сервера.

## Первый запуск
1. Язык → звук (микрофон и системный звук) → распознавание (загрузка ≈ 160 МБ).
2. Модель: [Ollama](https://ollama.com) подхватывается сама, иначе — провайдер и ключ.
3. Профиль и документы (PDF/DOCX/TXT).

## Системный звук, несколько выходов и SteelSeries Sonar

В автоматическом режиме Copilot захватывает звук устройства вывода Windows по умолчанию.
Sonar разделяет звук между виртуальными выходами Chat, Media, Gaming и Aux. Если звонок
или видео направлены на другой выход, автоматический захват может получать тишину,
хотя в наушниках звук слышен.

Чтобы выбрать нужный источник:

1. Откройте **Настройки → Речь и звук → Источник звука собеседника — устройство воспроизведения**.
2. Выберите выход, на который направлен звук: Sonar Chat для звонка, Sonar Media для видео
   либо фактические наушники/динамики. Например, `Headphones (SteelSeries Arctis Nova 5)`.
3. Включите речь в звонке или видео и нажмите **«Слышит ли собеседника?»**.
4. Начните новую сессию: выбранный выход применяется при её запуске.

**Режим стримера Sonar не требуется.** Собственный микрофон настраивается отдельно
в поле «Мой микрофон». В списке звука собеседника используются именно устройства
воспроизведения Windows, включая виртуальные выходы Sonar.

При отключении выбранного выхода приложение показывает ошибку и не подменяет его
другим источником; при возвращении устройства пытается переподключиться. Чтобы вернуть
прежнее поведение, выберите «Автоматически — системный звук» и начните новую сессию.

### Захват выбранного выхода Windows

Штатный `getDisplayMedia` / `audio: 'loopback'` в используемой версии Electron не даёт
выбрать произвольное устройство воспроизведения. Для явного выбора добавлен небольшой
Windows-помощник `resources/loopback.cs`, который перечисляет активные WASAPI render
endpoints и захватывает системный микс указанного выхода в shared loopback mode.
Автоматический режим продолжает использовать существующий захват Electron.

- `predev`, `prebuild` и `beforePack` автоматически запускают `scripts/build-loopback.cjs`.
  Для сборки на Windows нужен компилятор .NET Framework
  `%WINDIR%\Microsoft.NET\Framework64\v4.0.30319\csc.exe`.
- Скомпилированный `resources/bin/loopback.exe` включается в установщик отдельным ресурсом;
  бинарник не хранится в Git. Новых npm-зависимостей нет. Для запуска готовой сборки
  пользователю не нужны TypeScript, Node.js или компилятор.
- Windows преобразует поток в 16 кГц, mono, float32. Через канал процесса и IPC он попадает
  в существующие VAD и whisper.cpp как источник `remote`; сырое аудио не пишется на диск.
- Проверка уровня использует тот же путь захвата, что и сессия. Пауза, остановка сессии,
  перезагрузка/закрытие окна и выход из приложения освобождают захват.

`tests/audio.test.ts` проверяет выбор выхода, раздельный микрофон, ошибки, сохранение
настроек и отмену переподключения. `tests/loopback.test.ts` дополнительно проверяет
реальный WASAPI-поток на Windows: перед `npm test` выполните `npm run build`.
Аппаратный тест пропускается на других ОС, без собранного помощника или без активных выходов.

Проверено на Windows 11 x64 с SteelSeries Sonar и Arctis Nova 5: тестовый сигнал
захватывается отдельно с Sonar Chat и с наушников. Пользователь также подтвердил работу
распознавания речи в собранной версии. Остальные звуковые устройства и ОС отдельно не проверялись.
